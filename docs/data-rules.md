# Правила заполнения данных

Эти правила проверяют админка, импорт и `validate_data`. Полное ТЗ — [spec.md](spec.md), решения — [decisions.md](decisions.md).

## Песня

- **Название** — официальное, без пометок ремастера и редакций: не «Bohemian Rhapsody (Remastered 2011)», а «Bohemian Rhapsody».
- **Год** — первый официальный релиз песни (сингл или альбом), не ремастер и не сборник.
- **Исполнитель** — указанный на оригинальном релизе. **Каверы не используем.**
- **Приглашённые исполнители** (feat.) — отдельно от основного.
- **Участники группы** — заполняйте: по ним работает жёлтая плитка «исполнитель» (Queen ↔ сольная песня Freddie Mercury).
- **Страна** — страна основного исполнителя, на песне отдельно не хранится.
- **Жанр** — ровно один, **стили** — 1–2, только из справочника.
- **Вокал** — мужской, женский, смешанный (дуэт или группа с разными голосами) или «Instrumental».
- **Язык** — язык текста; для инструментальных — «No lyrics» (`zxx`).
- **Темы** — по смыслу **текста**, а не по настроению музыки; 1–2 темы, ровно одна главная. Инструментальные — по смыслу самого произведения.
- **Сложность** — насколько песню трудно угадать (для баланса расписания).
- **YouTube** — официальное видео: канал артиста, VEVO, лейбла или «… – Topic».
- **Источники** — ссылки, по которым проверены данные.

## Факты-подсказки

- Минимум **3 факта** на песню, у каждого — **ссылка на источник**.
- **Своими словами**, без цитат из текста песни.
- **Без названия песни, вариантов написания и имён** основного и приглашённых исполнителей и участников групп — проверяется автоматически, без учёта регистра и диакритики.
- Сила факта: `easy` — почти не выдаёт ответ (подсказка №1), `strong` — почти выдаёт (подсказка №2), `medium` — между ними.
- Прежде чем ставить «проверен», сверьте факт с источником.

## Статусы

`draft` (черновик, может быть неполным) → `review` (на проверке) → `verified` (подтверждена, участвует в игре).
Подтвердить можно только песню без ошибок проверки. Импорт никогда не перезаписывает песни на проверке и подтверждённые.

## Расписание

- Только подтверждённые песни, входящие в версию игры.
- Одна песня — не чаще раза в 365 дней.
- Один и тот же основной исполнитель — не два дня подряд.
- Предупреждение: 3 дня подряд один жанр или 3 сложные песни подряд.
- Проверка на 60 дней вперёд: `python manage.py check_schedule --days 60`.
